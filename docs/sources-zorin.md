# Fontes oficiais — Zorin OS

Esta nota registra as fontes usadas para completar a cobertura do Zorin OS no Stray Linux. As instruções publicadas devem manter os avisos de backup, Secure Boot e alteração de componentes de sistema descritos pelo projeto Zorin.

| Tema | Fonte oficial | Uso editorial |
| --- | --- | --- |
| Ciclo de suporte | [Zorin OS][1] | Referência de versão e política de atualizações da linha atual. |
| Instalação | [Install Zorin OS][2] | Etapas oficiais de instalação, mídia USB, teste de mídia e opção de boot para NVIDIA moderna. |
| Driver NVIDIA | [Activate NVIDIA Graphics Card][3] | Fluxo suportado pelo Zorin: instalador com opção NVIDIA ou aplicativo **Additional Drivers**, incluindo aviso de Secure Boot. |
| Atualização de versão | [Upgrade Zorin OS][4] | Atualização pelo aplicativo **Upgrade Zorin OS**, com backup e atualização via Software Updater antes do procedimento. |

> O Zorin recomenda ter cautela com repositórios de terceiros, alterações manuais de componentes centrais, scripts não oficiais e módulos externos de kernel antes de uma atualização principal. O Stray Linux não deve apresentar esses caminhos como recomendação padrão.[4]
